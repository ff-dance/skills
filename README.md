# Skills

这个仓库主要用于分享和生成实用型 AI Agent Skills，当前以 Codex 和 Claude 为主。

仓库目标很直接：
- 沉淀能够解决真实工作问题的可复用 skill
- 让每个 skill 都尽量清晰、实用、易于扩展
- 将 prompt 逻辑、参考资料、资产文件和工作流说明组织在一起

这类 skill 主要适用于以下场景：
- 结构化内容生成
- 演示文稿与文档生产
- 面向特定任务的工作流 prompt 封装
- 高频重复任务的 agent 行为复用

## 仓库结构

每个 skill 独立放在自己的目录中，通常包含以下内容：
- `SKILL.md`：skill 的主定义和使用工作流
- `references/`：规则、风格指南、示例等参考资料
- `assets/`：可选的图片、品牌素材或参考资产
- `scripts/`：可选的辅助脚本

## 已有 Skills

### `siemens-slides`

用于生成西门子风格的 slide 图片，尤其适合 Siemens Advanta 风格的企业演示页面。

典型使用场景：
- 封面页
- 目录页
- 结构化内容页
- 流程页与路线图页
- 表格页与框架页
- 引言页或观点页
- 联系页

路径：`siemens-slides/`

## 使用说明

- 这些 skill 主要面向 Codex 和 Claude 这类 agent 工作流
- 仓库更强调可落地的产出，而不是纯概念性的 prompt 实验
- 新增 skill 时，尽量保持模块化、可读性和可复用性

## 补充约定

新增 skill 时，建议至少写清楚以下内容：
- skill 是做什么的
- 什么场景下应该使用
- 什么场景下不应该使用
- 推荐的使用顺序或工作流
- 依赖的参考资料或资产文件
