# Siemens Advanta Style Guide

## 设计宪法

### 1. Action Title

- 每一页标题都必须是完整论断句，不是主题标签。
- 标题应优先接近“量化证据 + 因果判断 + 行动指向”。
- 禁止以 `分析`、`介绍`、`概况`、`说明` 等词收尾。

### 2. One Message Per Page

- 每页只回答一个决策问题。
- 如果同一页同时在回答“现状是什么、为什么、怎么做、谁负责”，通常说明应拆页。

### 3. Evidence-Backed

- 每个核心判断都必须有至少一个视觉证据锚点。
- 证据可以是 hero number、对比、图表式块、流程证据、优先级结构、before/after。
- 纯文字页通常表示内容还没有完成咨询化结构。

### 4. Ghost Deck

- 页面在没有讲解的情况下也要能被读懂。
- 受众应能通过标题、核心证据和结论收束快速理解这页在证明什么。

### 5. Restraint

- 页面应像 Siemens 企业咨询 / 战略汇报页，不像海报、广告、网页 hero 或 startup pitch。
- 留白必须服务于网格、层级和阅读节奏，而不是元素没对齐留下的空。

## 品牌系统

### 核心气质

- Deep Blue、克制、咨询级、品牌驱动、数据导向、现代企业、Teal/Petrol 点缀
- 装饰度极低，强调网格、留白、层级、数据和结构

### 官方色板

- Deep Blue: `#000028`
- White: `#FFFFFF`
- Siemens Petrol: `#009999`
- Light Petrol: `#00C1B6`
- Advanta Green: `#E6E65F`
- Soft Green: `#00D7A0`
- Soft Blue: `#00BEDC`
- Deep Blue 80: `#333353`
- Deep Blue 60: `#66667E`
- Deep Blue 40: `#9999A9`
- Deep Blue 20: `#CCCCD4`
- Deep Blue 10: `#E5E5E9`
- Sand: `#F3F3F0`, `#DFDFD9`, `#C5C5B8`, `#AAAA96`
- Risk Orange: `#E37200`

### 语义色映射

- `结论 / 权威`：Deep Blue `#000028`
- `主论点强调 / hero evidence`：Siemens Petrol `#009999`
- `改善 / 收益 / 正向机会`：Advanta Green `#E6E65F` 或 Soft Green `#00D7A0`
- `数字化 / AI / 技术辅助`：Light Petrol `#00C1B6` 或 Soft Blue `#00BEDC`
- `流程 / 系统 / 连接`：Light Petrol 优先
- `风险 / 警示 / 紧迫问题`：Risk Orange `#E37200`
- `辅助说明 / 注释 / 页脚`：Deep Blue 60 `#66667E`

### 页面区域用色

- 浅色内容页：背景默认 `#FFFFFF`，标题和正文默认 Deep Blue。
- 深色页：背景默认 Deep Blue，正文 White，强调只允许品牌浅亮色。
- hero 区只允许一个主强调色，默认 Siemens Petrol。
- Light Petrol 只用于流程箭头、连接件和次级技术感辅助。
- Advanta Green 只用于少量正向强调，不得与主强调色平权并列。
- Orange 只用于受控风险提示。
- takeaway strip 默认优先 Siemens Petrol；只有需要更正式、更结论性的收束时才用 Deep Blue。
- 不要使用接近品牌色但不在色板内的“相似色”。

### Icon / Glyph 用色规则

- 浅色内容页中，默认功能 icon、业务 icon、能力 icon、section header 小图标优先使用 Deep Blue `#000028`。
- 流程箭头、流向 icon、连接件、阶段节点描边可使用 Light Petrol `#00C1B6`，但只在流程 / 系统 / 连接语义中使用。
- hero 区中的小型 icon cue 可使用 Siemens Petrol `#009999`，并从属于 hero 主强调色。
- 风险、告警、数据纪律相关 icon 才允许使用 Risk Orange `#E37200`。
- 正向收益、推荐、改善类小型 icon 才允许少量使用 Advanta Green `#E6E65F` 或 Soft Green `#00D7A0`。
- 同一内容区内，icon 颜色数量默认不超过 2 种；如果没有明确语义区分，优先统一用 Deep Blue。
- 不要把 icon 统一画成接近 Siemens Petrol 的近似 teal；颜色必须服从语义色规则。

### 页面边界

- 页面固定 `16:9`
- 左右安全区约 `0.45"`，对应约 `3.4%` slide width
- 标题区靠近顶部，内容区从约 `1.55"` 开始
- 模板只提供这些边界，不提供布局答案

### Footer / Brand Zone

默认保留完整的 corporate brand zone：
- 左下页码：`Page X`
- 左锚定页脚文字带：`Restricted | © Siemens 20XX | YYYY-MM-DD`
- 右下品牌位：`SIEMENS`

  - `y = 6310800 EMU`

  - `height = 547200 EMU`
  - `x = 8.69%`

提取来源与变体说明：
- 精确坐标提取自 Advanta 模板源文件，并整理为本仓库参考数据
- 详见 `references/footer-geometry-extracted.md`
- 普通内容页使用 compact `SIEMENS` logo family；封面 / 章节 / 特殊页允许使用更大的 large logo family，但不要混用到普通内容页

Footer 规则：
- 页码与页脚文字带必须共用同一基线，几乎贴齐，不得远离漂浮。
- `page_zone.right_edge` 与 `footer_zone.x` 在母版中几乎无缝衔接，间隔可视为 `0`；不要人为拉开。
- 页脚文字带必须从页码右侧几乎立即开始，视觉上像同一条底部信息带，而不是页面中央单独悬浮的一段文字。
- 页脚文字带必须左对齐并左锚定在 footer zone 起点，不得做居中对齐，也不得把整段 footer text 的光学中心放到页面中线附近。
- takeaway、正文和主图形不得侵入 footer band。
- `SIEMENS` 只作为品牌区元素，不得被放大成主视觉对象。
- 浅色普通内容页默认使用 compact `SIEMENS` logo 几何，不使用更大的封面/特殊版式 logo family。
- 浅色内容页中，右下 `SIEMENS` 品牌字标默认必须使用 Siemens Petrol `#009999`。
- 深色页中，右下 `SIEMENS` 品牌字标可使用 White `#FFFFFF`。
- 允许修改 footer 文案，但不允许修改三分区几何关系。

### 浅色 / 深色模式

- `light`：默认模式，白底、Deep Blue 标题与正文
- `dark`：用于摘要、章节、强调结论页
- `light-sand`：仅在明确需要更柔和浅底时使用
- 不要无理由深浅乱切

## 信息层级

- `L1` 行动标题：3 秒可读，给出结论
- `L2` 核心证据：10 秒可读，给出最大证明
- `L3` 支撑论据：30 秒可读，支撑标题判断
- `L4` 细节标注：说明数据来源、假设、注释
- `L5` 底部收束：回答“所以呢”

如果一个页面没有清晰的 L2 或 L5，通常会显得像普通排版页而不是咨询页。

## 页面生命力

### 生动但克制

- 生动感是所有论证模式通用的页面气质，不绑定某个 layout 或某种固定结构。
- 页面不应是纯文字墙；至少一个主要内容区应承担结构化视觉节奏。
- 在品牌边界、单一 page question 和统一网格不被破坏的前提下，允许局部打破完全对称，让模型创造更自然的主次与节奏。
- 允许局部使用：
  - compact technical glyph icons
  - 节点链
  - 细连接线
  - mini-process
  - icon-assisted summary
  - 局部关系结构
- 允许一个主内容区比其他区域更具 signature character，例如更强的 hero evidence、局部嵌入流程或非同构分区。
- 生动感来自结构化节奏，而不是多色、大装饰、夸张形状。

### 组件总原则

- 全部使用直角矩形，不使用 rounded corners，不使用 pill 形状
- 默认无明显阴影；只允许极轻微、接近模板默认效果的阴影
- 内容 text 区域、说明框、注释框默认不用虚线边框
- 同类组件必须共用列宽、边界线和间距节奏

## 禁止项

- 不要 emoji、贴纸、卡通化元素、多彩消费级元素混搭
- 不要居中海报式构图、startup landing page、霓虹 HUD、3D 图表、玻璃拟态
- 不要边框、相框、下划线式标题装饰
- 不要把底部重点内容区做成多色拼接卡片带
- 不要让所有主要内容区完全同构且都变成文字块
- 不要把内部方法词原样写进页面，例如 `MECE`、`reasoning pattern`、`layout`
- 不要把本地文件路径原样当成模型可见参考图
