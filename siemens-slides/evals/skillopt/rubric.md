# Siemens Slides SkillOpt Rubric

本 rubric 只面向中文咨询页。

## Gate 顺序

1. 先跑 `scripts/skillopt_spec_lint.py`
2. 只有 P0 全过的候选 `slide_spec` 才进入 LLM judge
3. 只有 `val` split 的总分严格提升，候选 skill 才能接受

## Judge 维度

每个维度建议按 `0 / 1 / 2 / 3` 评分：

### 1. `Action Title` 强度

- `0`：主题词，或以 `分析/介绍/概况/说明` 收尾
- `1`：像结论句，但判断弱、没有行动指向
- `2`：结论明确，基本能驱动页面
- `3`：结论清晰、因果明确、具备管理层可读性

### 2. Pattern 匹配度

- `0`：`reasoning_pattern` 与任务明显不符
- `1`：勉强可用，但更像错位借用
- `2`：基本匹配
- `3`：高度匹配，能自然承接论证任务

### 3. Layout 承载度

- `0`：layout 与 pattern 明显冲突
- `1`：能放下内容，但不支持核心逻辑
- `2`：基本匹配
- `3`：能强化主要结论与阅读节奏

### 4. Evidence-Backed 程度

- `0`：没有明确 `key_evidence`
- `1`：有证据字段，但很弱或不支持结论
- `2`：存在清晰证据锚点
- `3`：证据锚点清晰且能成为页面 L2 hero

### 5. Ghost Readability

- `0`：标题、证据、结论不能串起来
- `1`：需要较多讲解才能读懂
- `2`：基本能独立阅读
- `3`：只看标题、hero、takeaway 就能理解主结论

### 6. 中文咨询表达稳定性

- `0`：混入英文默认表达、口号化或营销化
- `1`：基本中文，但像普通文档或工作记录
- `2`：像合格汇报页
- `3`：稳定呈现 Siemens corporate consulting 语气

### 7. Overflow 处理

- `0`：多问题输入仍强行单页
- `1`：意识到超载，但处理含糊
- `2`：给出合理 `suggest-split` 或 `compressed-single-page`
- `3`：压缩策略或拆页建议明确且可信

## 推荐判定

- 单题总分建议满分 `21`
- 经验门槛建议：
  - 单题 `< 11`：失败
  - 单题 `11-15`：可用但弱
  - 单题 `16-18`：合格
  - 单题 `19-21`：强

`val` split 接受规则：

- 新候选总分必须严格高于当前 best
- 如总分持平，保持当前 best，不接受替换
