# Siemens Advanta Storytelling

`siemens-storytelling` 是一个面向咨询顾问、售前顾问、解决方案顾问和项目交付团队的 Codex Skill，用于把客户背景、业务痛点、方案方向和汇报目标转化为适合制作 PPT 的咨询式 Storytelling。

它的核心目标是帮助用户把零散信息组织成一条能推动客户形成共识和行动的叙事逻辑，而不是简单生成目录或产品功能清单。

## 适合场景

- 售前客户方案：数字化工厂、智能制造、MES/MOM、IT/OT 融合、工业软件平台、能源管理、供应链数字化等方案汇报
- 高管汇报：数字化转型战略、项目立项、Steering Committee、投资决策、转型路线图
- 咨询项目交付：现状诊断、差距分析、目标蓝图、实施路线图、阶段汇报、最终交付
- 客户 Workshop：共创研讨、成熟度评估、高价值场景识别、场景优先级排序、需求澄清

## 能生成什么

- 一句话故事线
- SCQA 故事线
- PPT 章节结构
- 逐页 Slide 大纲
- 每页 Key Message
- 推荐图表和版式
- 详细讲述逻辑
- 咨询式表达建议
- Storytelling 自检清单

## 安装方式

把整个 `siemens-storytelling` 目录放到技能目录下：

```
~/.codex/skills/siemens-storytelling
```

最终目录结构应类似：

```
siemens-storytelling/
├── SKILL.md
├── README.md
├── agents/
│   └── openai.yaml
└── references/
    └── storytelling-frameworks.md
```

安装后，可以通过 `$siemens-storytelling` 显式调用；在界面中显示为 `Siemens Advanta Storytelling`。

## 快速开始

可以直接这样提问：

```
请使用 $siemens-storytelling 生成一个咨询式 PPT Storytelling。

客户是汽车零部件制造企业，听众是 COO、工厂厂长和 IT 负责人。
目标是推动后续联合 Workshop。
客户痛点包括生产过程不透明、质量追溯困难、设备停机较多、系统之间数据不打通。
希望 15 页左右，偏咨询方案，不要太产品化，需要体现 Siemens 的端到端能力。
```

也可以这样快速调用：

```
请使用 $siemens-storytelling 帮我生成一个数字化工厂售前方案 storytelling。
客户是电子制造企业，听众是 COO 和 IT 负责人。
痛点是生产计划频繁变更、现场数据不透明、质量问题定位慢、设备利用率不高。
目标是推动后续 Workshop，页数 12-15 页，需要体现 Siemens 能力，但不要太产品化。
```

## 推荐输入模板

信息越完整，输出越接近可直接做 PPT 的程度：

```
请基于以下信息生成咨询式 PPT Storytelling 和逐页大纲：

1. 客户行业：
2. 客户背景：
3. 汇报对象：
4. PPT 目标：
5. 汇报时长：
6. 期望页数：
7. 当前痛点：
8. 目标方向：
9. 希望重点展示的方案或能力：
10. 是否需要体现 Siemens 相关能力：
11. 是否偏战略、业务、技术、销售或项目交付：
12. 输出语言：
13. 其他要求：
```

如果信息不完整，Skill 会优先提出少量关键澄清问题。若你希望快速得到初版，可以明确写：

```
信息不完整也没关系，请基于合理假设先给初版，并列出关键假设。
```

## 输出特点

默认完整输出包括：

1. 对汇报目标的理解
2. 一句话故事线
3. SCQA 故事线
4. 核心叙事逻辑
5. 推荐章节结构
6. 逐页 Slide 大纲
7. 详细讲述逻辑
8. 关键表达建议
9. 可视化建议
10. Storytelling 自检清单

对于高管汇报，Skill 会更强调战略意义、业务价值、投资优先级、风险和决策事项。对于技术方案，Skill 会保留业务叙事，同时补充架构、数据流、系统集成、实施依赖和风险控制。

## 设计原则

- 从客户业务问题出发，而不是从产品功能出发。
- 先建立背景和挑战，再分析根因，然后提出目标蓝图、解决方案、实施路径和业务价值。
- 每页 Slide 只有一个清晰的 Key Message。
- Slide 标题尽量使用观点句，而不是名词短语。
- Siemens 能力表达服务于客户问题，避免产品堆砌。
- 不编造客户数据、财务收益或未经验证的案例。
- 如需收益数字，应标注为假设或待验证。

## 示例：普通表达改写

普通表达：

```
Siemens 有很多先进产品，可以帮助客户实现数字化工厂。
```

咨询式表达：

```
针对客户当前在生产透明化、质量追溯和设备效率方面的挑战，建议以业务场景为牵引，结合自动化、工业软件、数据集成和数字化咨询能力，构建从现场数据到管理决策的端到端运营闭环。
```

## 适用边界

本 Skill 生成的是故事线、结构和大纲，不会自动生成最终 PPT 文件。若需要进一步制作 Siemens 风格页面或 PowerPoint，可将输出的大纲作为后续页面设计和制作的输入。

本 Skill 不会访问或引用未提供的 Siemens 内部资料，也不会声称任何未经验证的客户案例或收益数据。
